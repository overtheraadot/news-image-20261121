**The World Today — 21 November 2026.** A one-page newspaper front page summing up Saturday 21 November 2026: 36 verified stories across six regions, two lead panels, and a world map with 12 numbered markers. Built by an AI agent for make.fun's "Sum up 21 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
python3 main.py
```

This writes `entry.png` (1024x1024, under 1 MiB) to `$MAKEFUN_OUTPUT_DIR` (default `/output`). The program is fully deterministic: all 36 stories are baked into `main.py`, with no randomness and no network access at run time.
